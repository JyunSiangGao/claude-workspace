# 正覺弘法視頻搜尋

搜尋 [正覺教團弘法視頻](https://video.enlighten.org.tw/zh-tw/) 所有節目的文字稿。輸入名詞（例如「如來藏」「四聖諦」），就會列出：

- 哪些節目提到這個名詞，每集出現幾次，各系列出現幾次
- 每次出現的前後文，可以展開看整段
- 大約在第幾分幾秒，點一下就從那附近開始播放 YouTube 影片
- 每集的時間軸，看出名詞集中在節目的哪一段
- 名詞說明與相關詞（例如搜「阿賴耶識」也會找到「第八識」「藏識」），並附節目中老師解釋這個名詞的原文
- 名詞辭典：222 個名詞，可瀏覽、篩選
- 節目瀏覽：依系列看每集摘要、重點與主題標籤（「三乘菩提」29 個系列、約 3,360 集都有摘要）
- 「法義辨正」4 個系列（明心與初地釋、宗門與教門、壇經辨訛、力挽狂瀾，共 54 集）也已收錄；官網這個分類只提供影片、沒有文字稿，前三個系列（49 集）的文字是用語音辨識產生的，可以搜尋內容但會有錯字（見下面「語音辨識」一節）；「力挽狂瀾」5 集只能用標題找到並播放
- 經常和它一起出現的其他名詞
- 可以只看某個系列或某位老師（在「更多搜尋選項」裡），結果可以下載成 CSV（Excel 可開）
- 右上角 A− / A＋ 可調整字體大小，旁邊的「深色／淺色」可切換畫面配色；瀏覽器的「上一頁」可回到前一次搜尋；首頁會列出最近搜尋過的名詞
- 搜尋結果左邊是節目列表，右邊是統計、名詞說明與相關名詞（手機上排在列表前面，說明先收合）；列表可切換「詳細／精簡」，精簡模式每集一行，點了才展開
- 一集出現很多次時，時間軸會改成濃淡色條，顏色越深代表那一段越集中
- 播放器有「−15 秒／＋15 秒」與「上一處／下一處」，列表中會標示正在播放的那一段
- 同時搜尋 [正智書香園地](https://books.enlighten.org.tw/zh-tw/) 的正覺電子報、贈閱書籍與正智影音（見下面「書刊」一節）

所有搜尋都在瀏覽器裡進行，不需要伺服器，也不需要網路（播放影片除外）。

## 使用方式

把整個資料夾放在電腦上（例如 `D:\學佛影片搜尋`），然後：

- **Windows：雙擊 `開啟搜尋.bat`**。會跳出一個黑色視窗並自動打開瀏覽器，影片可以直接在網頁裡播放。
  - 使用期間不要關掉那個黑色視窗（可以縮到最小）；用完後把它關掉就停止了。
  - 已經開著時再雙擊一次也沒關係，只會再打開一次瀏覽器。
  - 需要 Python 3.9 以上。沒有 Python 時會改成直接打開 `index.html`，仍可搜尋，但影片改在 YouTube 新分頁播放。
- 其他系統：執行 `python tools/serve.py`，或直接用瀏覽器打開 `index.html`。

第一次打開需要幾秒鐘載入全部文字稿。

## 關於時間

網站的文字稿沒有時間標記，所以影片時間是**估算**的：用名詞在文字稿中的位置比例，乘上節目長度（從網站提供的 mp3 讀取）。估算值通常和實際相差幾十秒以內，所以點時間播放時會**提早 15 秒**開始。需要精確位置時，可以點「看整段」對照文字，或打開「文字稿」頁面。

## 更新資料

網站有新節目時，**雙擊 `更新資料.bat`**（需要 Python 3.9 以上與網路），它會執行：

```bash
python tools/build_index.py
```

只會下載新的節目，以及之前還沒有文字稿的節目（網站上顯示「敬請期待」的）。中途可以按 Ctrl+C 停止，下次會接著下載。完成後在搜尋網頁按 F5 重新整理。

注意：

- 第一次執行會在資料夾裡建立 `cache/`（下載的原始資料，約數十 MB），之後更新才不用全部重抓，請不要刪除。
- 更新只會加入新節目的文字稿與搜尋；新節目不會自動產生「每集摘要」和名詞辭典的原文摘錄。

- `更新資料.bat` 接著會執行 `python tools/build_books.py` 更新書刊（電子報每月出刊）。這一步需要多裝一個讀 PDF 的套件，只要裝一次：

```bash
python -m pip install pymupdf
```

其他用法：

```bash
python tools/build_index.py --series a29
```

只更新某個系列（系列代號見首頁的系列表；「三乘菩提」是 a01～a29，「法義辨正」是 b01～b03 與 c01）。

```bash
python tools/build_index.py --build-only
```

不連網，只重建索引；修改名詞表之後執行，首頁的「常見名詞」次數才會更新。

## 語音辨識（官網沒有文字稿的節目）

「法義辨正」的節目官網只有影片與 mp3、沒有文字稿。`tools/transcribe.py` 會下載 mp3，用語音辨識（faster-whisper）轉成文字，存在 `data/asr/`，重建索引後就能搜尋內容。

- **雙擊 `語音辨識.bat`** 就會辨識還沒做的節目，做完自動重建索引。很花時間（一集約一小時的節目要跑十幾分鐘到幾十分鐘），可以隨時關掉視窗，下次再執行會從還沒做的那一集繼續。
- 辨識軟體裝在 `D:\whisper-asr`（獨立的 Python 環境與模型，不在這個資料夾裡）。不需要時整個刪掉即可，已經辨識好的文字不受影響。有 NVIDIA 顯示卡時會自動用顯示卡跑（GTX 1050 約 5 倍速，49 集約 6.5 小時），沒有就用 CPU（約 1.2 倍速）。
- 辨識出來的文字**會有錯字**，尤其是佛學名詞與同音字，網頁上會標示「語音辨識文字」。搜不到時可以試試同音的寫法。
- 這些節目的播放時間是辨識時得到的**實際時間**，不是估算的，所以時間前面沒有「約」字，播放時只提早 4 秒。
- 「力挽狂瀾」（c01）官網沒有提供 mp3，所以沒有辨識，只能用標題找到。

## 書刊（正智書香園地）

除了弘法視頻，也收錄 [正智書香園地](https://books.enlighten.org.tw/zh-tw/) 的三個分類，搜尋時會和影片一起列出：

| 分類 | 數量 | 可以搜尋的內容 |
| --- | --- | --- |
| 正覺電子報 | 190 期（第 1～3 期、第 31～217 期；第 4～30 期官網沒有列出） | 每一期的 PDF 全文，約 1,747 萬字 |
| 贈閱書籍 | 89 本 | 10 本有 PDF 全文；其餘 79 本只有官網頁面上的簡介與目錄 |
| 正智影音 | 24 項 | 官網頁面上的說明，並附下載／播放連結 |

- 書刊的搜尋結果標示的是**頁碼**（不是時間）。點「第 N 頁」會在新分頁開啟官網的 PDF 並跳到那一頁；「官網簡介」則開啟官網上那本書的頁面。頁碼是 PDF 檔的第幾頁，和書上印的頁碼可能差幾頁。
- 搜尋結果上方有「全部／影片／書刊」可以切換；「更多搜尋選項」裡也可以只選電子報、贈閱書籍或影音。
- 「節目瀏覽」裡可以選這三個分類，逐期、逐本瀏覽。
- 書刊資料比較大（約 50 MB），會在影片文字稿載入完之後才在背景載入，載入期間畫面上會顯示進度，這時搜尋到的書刊結果可能還不完整。

**為什麼大部分贈閱書籍只能搜尋簡介：** 89 本裡有 75 本的 PDF 被出版社設定為不允許複製與擷取文字，腳本遇到這種檔案不會去破解，只收錄官網頁面上公開的簡介與目錄，並附上 PDF 連結讓你自己打開閱讀；這些書在網頁上會標示「只能搜尋簡介」。另外 4 本官網沒有提供 PDF。有全文的 10 本是 9 部經典（《金剛經》《勝鬘經》《維摩詰經》《妙法蓮華經》《楞嚴經》《優婆塞戒經》《解深密經》《菩薩瓔珞本業經》《佛藏經》）與《一位哲學博士的懺悔》。

其他說明：

- PDF 擷取出來的文字偶爾會有斷行位置不對、頁首頁尾混入、罕用字變成別的字的情形，引用時請以 PDF 原文為準。
- 下載時用 `python tools/build_books.py --keep-pdf` 會把 PDF 留在 `cache/books/pdf/`（約 1.2 GB）；只有修改擷取規則後要重新擷取（`--reextract`）時才用得到，不需要的話可以整個刪掉，不影響搜尋。
- `python tools/build_books.py --only e` 只更新電子報（`g` 是贈閱書籍、`m` 是影音）；`--build-only` 不連網、只重建書刊索引。

## 名詞辭典

點右上角「名詞辭典」可瀏覽全部 222 個名詞。最上面是名詞索引，點了會跳到該名詞並展開；下面每個名詞一列，點了才展開。每個名詞有：

- 簡短說明（部分名詞有，可自行修改）
- **節目中的說法**：從文字稿裡挑出老師解釋這個名詞的段落，再依這些段落整理的摘要
- **節目原文摘錄**：2～4 段原文，附系列、集數、主講老師，點時間可直接播放

搜尋名詞時，結果上方也會顯示同樣的說明。「節目中的說法」與原文摘錄存在 `data/definitions.js`，是一次性整理的結果；之後新增的節目不會自動加入摘錄。

## 節目瀏覽與每集摘要

點右上角「節目瀏覽」，選擇系列後會依集數列出每一集。所有系列中有文字稿的節目（約 3,360 集）每集都有：

- 2～3 句摘要
- 3～5 個重點
- 3～6 個主題標籤，上方的「常見主題」可一鍵篩選，例如「授記」「化城喻」「一佛乘」

搜尋時也會比對摘要，符合的節目會標示「本集摘要提到」。摘要是 AI 讀完整集文字稿後整理的，只供快速瀏覽與找節目，內容請以原文為準。摘要存在 `data/summaries.js`。

## 增修名詞說明

編輯 `data/glossary.js`，每個名詞一筆：

```js
{ term: "阿賴耶識", aliases: ["第八識", "藏識"], desc: "唯識學所說的第八識……" },
```

- `term`：主要名詞
- `aliases`：相關詞、別名（勾選「含相關詞」時會一起搜尋）。請避免只有一個字或容易出現在一般句子裡的詞（例如「我見」會搜到「我見到」）。
- `desc`：顯示在搜尋結果上方的說明（可留空）

## 檔案說明

| 檔案 | 用途 |
| --- | --- |
| `index.html`、`assets/` | 搜尋網頁 |
| `開啟搜尋.bat` | Windows 用：雙擊開啟搜尋網頁 |
| `更新資料.bat` | Windows 用：雙擊下載網站的新節目並重建索引 |
| `tools/serve.py` | 本機小伺服器（由 `開啟搜尋.bat` 呼叫） |
| `data/catalog.js` | 系列清單與統計（由腳本產生） |
| `data/series/*.js` | 每個系列的文字稿（由腳本產生） |
| `data/glossary.js` | 名詞說明與相關詞 |
| `data/definitions.js` | 節目中的說法與原文摘錄 |
| `data/summaries.js` | 每集摘要、重點與主題標籤 |
| `tools/build_index.py` | 下載文字稿、建立索引的腳本 |
| `data/books_catalog.js` | 書刊清單與統計（由腳本產生） |
| `data/books/*.js` | 電子報、贈閱書籍、影音的內容（由腳本產生） |
| `tools/build_books.py` | 下載書刊、擷取 PDF 文字、建立書刊索引的腳本 |
| `cache/` | 更新資料時下載的原始資料（第一次更新後才會出現）；`cache/books/` 是書刊的 |

兩個 `.bat` 檔刻意只用英數字：Windows 的命令列讀到含中文的批次檔時，可能漏掉下一行指令（伺服器沒啟動、瀏覽器卻打開，出現「無法連上這個網站」）。要改提示文字請改 `tools/serve.py`。
